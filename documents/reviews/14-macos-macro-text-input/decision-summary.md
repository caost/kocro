# 이슈 #14 결정 요약

- 매크로 실행 순서는 문자열, 키 조합과 딜레이 단계의 배열로 구성한다.
- 처음 사용하는 사람이 구분 문법을 익히지 않아도 되도록 하나의 동작을 하나의 행으로 표시한다.
- 쉼표와 줄바꿈으로 전체 순서를 작성하는 통합 입력 문법은 제공하지 않는다. 문자열 안의 쉼표와 줄바꿈은 값 그대로 보존한다.
- 각 단계 행은 종류별 편집기와 삭제·위·아래 이동 동작을 제공한다.
- 현행 요구사항은 `documents/spec/platform/macos-macro-text-input.md`와 `documents/spec/platform/macos-final-ui.md`에 반영한다.
