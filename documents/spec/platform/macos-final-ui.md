# macOS 최종 화면 설계

## 목적

이 문서는 `documents/spec/platform/macos-macro-text-input.md`에서 정한 저장, 권한,
단축키 등록과 입력 실행 동작을 바꾸지 않고 Kocro 설정 창, 메뉴 바 메뉴와 About
화면의 최종 정보 구조와 상호작용을 정한다.

두 문서의 화면 표시 규칙이 다른 경우 이 문서가 다음 항목만 대체한다.

- 빈 `MacroDefinition.title`의 설정 화면 표시
- F21~F24 제거 뒤 지원 키 안내
- 메뉴 바 최근 실행의 사용자 제목 또는 UUID 표시

저장 트랜잭션, 키별 기록 가능 범위와 단축키 등록 실패 처리는 기존 스펙을 그대로
따른다.

설계 기준은 2026-09-06에 승인한 HTML 시안의 다음 결정이다.

- 설정 창은 `일반`과 `매크로` 상단 탭을 사용한다.
- 매크로 목록은 선택한 항목 하나만 펼치는 접이식 카드로 표시한다.
- 단축키와 후속 키는 VIA 형식의 토큰 문법을 직접 입력하거나 실제 키를 기록한다.
- 삭제는 저장 전까지 취소할 수 있고 실행 설정은 저장 성공 뒤에만 교체한다.
- 메뉴 바 메뉴는 최근 실행 결과를 포함하고 About은 별도 표준 패널로 연다.

## 설정 창

### 공통 구조

- 설정 창 상단에는 아이콘과 라벨을 함께 표시한 `일반`, `매크로` 탭을 둔다.
- 처음 열 때는 `매크로` 탭을 선택한다.
- 메뉴 바에만 상주할 때는 accessory 앱으로 동작한다. 설정 창을 열면 activation
  policy를 regular로 바꿔 Dock과 Command-Tab 앱 전환기에 표시하고, 설정 창을 닫으면
  accessory로 되돌린다.
- 설정 창의 최소 크기는 접이식 카드의 필드와 도움말이 잘리지 않는 범위로 정하되,
  현재의 1,100포인트 고정 너비를 요구하지 않는다.
- `일반` 탭은 로그인 시 실행, Accessibility 권한과 민감한 정보 저장 주의를 표시한다.
- 권한 상태는 `허용됨` 또는 `권한 필요`로 표시하고 시스템 설정을 여는 동작을
  같은 영역에서 제공한다.
- 기존 설정 파일을 읽거나 검증할 수 없는 상태에서는 현재 선택한 탭과 관계없이 창
  상단에 `저장하면 기존 설정 파일을 기본 설정으로 교체합니다.` 경고 배너를 표시한다.
  경고 배너는 첫 저장이 성공할 때까지 유지하며 저장 실패 시 사라지지 않는다.

### 매크로 탭

상단에는 `매크로` 제목, “단축키를 누르면 설정한 문자열과 선택적인 후속 키를
입력합니다.” 설명과 지원 키 코드 도움말 링크를 표시한다. 도움말은 앱 안에서
지원하는 토큰과 키 범위를 설명하며 외부 QMK 문서만 단독으로 연결하지 않는다.

매크로는 저장된 순서대로 카드 목록에 표시한다. 카드 헤더에는 다음 정보를 한 줄로
배치한다.

- 순서 변경용 드래그 핸들
- 활성화 스위치 토글
- 제목 입력란
- 등록 상태 배지
- 삭제 버튼
- 펼치기·접기 버튼

제목 입력란은 사용자가 입력한 `MacroDefinition.title`이 있으면 그 값을 표시한다.
제목이 비어 있으면 입력 문자열의 첫 줄을 Swift `String`의 `Character` 기준으로
계산해 앞 10자를 자동 제목으로 표시한다. 첫 줄이 10자를 초과하면 10자 뒤에 `…`를
붙이고, 첫 줄이 비어 있으면 뒤의 줄에 내용이 있어도 `새 매크로`를 표시한다. 자동
제목은 화면용 값이며 사용자가 제목을 편집하기 전에는 `MacroDefinition.title`에
저장하지 않는다.

카드를 접으면 제목, 단축키와 상태를 헤더에서 확인할 수 있다. 단축키는
`{KC_CMD}`, `{KC_C}`처럼 토큰마다 별도 블록으로 표시한다. 카드를 펼치면 다음 필드를
표시한다.

- 실행 단축키
- 입력할 문자열과 현재 글자 수/10,000자 제한
- 선택적인 후속 키
- 해당 항목의 검증·등록 오류

한 번에 카드 하나만 펼친다. 저장된 설정을 처음 표시할 때는 모든 카드를 접는다.
새 매크로를 추가하면 새 카드를 목록 끝에 만들고 그 카드만 펼친다. 접힌 카드의
헤더나 펼치기 버튼을 선택하면 기존 카드를 접고 선택한 카드를 펼친다. 검증 또는
저장에 실패하면 첫 번째 오류가 있는 카드를 자동으로 펼치고 해당 입력으로 포커스를
옮길 수 있어야 한다.

상태 배지는 적어도 다음 상태를 구분한다.

| 상태 | 표시 |
| --- | --- |
| 비활성 항목 | `비활성` |
| 저장 전 추가 또는 변경 | `저장 전` |
| Carbon 등록 성공 | `등록됨` |
| 단축키 등록 충돌 | `충돌` |
| 그 밖의 등록 실패 | `등록 실패` |

하나의 항목에 여러 상태가 해당하면 `충돌`, `등록 실패`, `저장 전`,
`비활성`, `등록됨` 순서로 하나를 표시한다. 등록 결과 오류를 초안 변경 표시보다 먼저
보여주고, 저장 전 상태에서는 저장 이전 등록 결과를 배지의 보조 설명으로 제공할 수
있다.

### 토큰 편집기

실행 단축키와 사용자 지정 후속 키는 같은 토큰 편집기 동작을 공유하되 각 필드의
허용 키 규칙은 `documents/spec/platform/macos-macro-text-input.md`를 따른다.

- 표준 표기는 `{KC_CMD}+{KC_F13}`처럼 중괄호 토큰을 `+`로 연결한다.
- 사용자는 토큰 문법을 직접 입력하거나 붙여넣을 수 있다.
- `{KC_`를 입력하면 해당 필드에서 허용하는 키만 자동완성하고 화살표 키로 이동한 뒤
  Enter 또는 Tab으로 선택한다.
- `키로 기록`을 선택한 뒤 실제 키 또는 키 조합을 누르면 같은 토큰 값으로 채운다.
- 키를 기록한 뒤에도 버튼 라벨은 `키로 기록`으로 유지한다. 기록한 값은 실행
  단축키 또는 후속 키 텍스트 입력란에만 표시한다.
- 포커스를 옮기거나 저장할 때 별칭과 입력 순서를 표준 표기로 정규화한다. 예를 들어
  `{KC_F13} + {KC_LCMD}`는 `{KC_CMD}+{KC_F13}`으로 바꾼다.
- 파싱할 수 없는 입력은 지우지 않는다. 지원하지 않는 토큰이나 기준 키가 둘 이상인
  위치를 표시하고 구체적인 수정 방법을 안내한다.
- 실행 단축키 기록 중 Escape는 기존 값을 유지하고 기록을 취소한다. 사용자 지정 후속
  키 기록 중에는 Escape, Delete와 Backspace를 값으로 기록하며 별도 `지우기` 동작으로
  값을 비운다. macOS가 먼저 처리한 조합은 직접 입력할 수 있다는 안내를 표시한다.
- 실행 단축키와 후속 키는 각각의 허용 범위로 검증한다. F21~F35는 직접 입력,
  자동완성, 선택 메뉴와 `키로 기록`에서 모두 제외한다.
- Command만 사용하는 표준 편집·파일·윈도우·앱 단축키는 기록 직후
  `이미 사용 중인 단축키입니다`로 안내하고 저장하지 않는다. 다른 보조 키 조합과
  앱별 단축키는 이 사전 검증으로 추측하지 않으며 실제 Carbon 등록 결과로 충돌을
  판정한다.

지원 키 코드 도움말은 실행 단축키와 후속 키를 구분해 지원 토큰, 별칭, 일반 키의
보조 키 요구 조건, F13~F20 지원과 F21~F35 미지원, 후속 키에서 허용하지 않는 키를
설명한다.

### 추가·삭제·순서 변경·저장

- `매크로 추가`는 비활성 상태이고 제목·단축키·문자열·후속 키가 비어 있는 초안을
  목록 끝에 추가한다.
- 드래그 핸들로 카드 순서를 바꾸면 초안 배열 순서도 함께 바뀐다.
- 삭제 버튼은 항목을 초안에서 제거하고 화면 아래에 `매크로를 삭제했습니다.`와
  `실행 취소` 동작을 표시한다.
- 연속해서 삭제하면 삭제한 항목과 원래 위치를 차례로 보관한다. `실행 취소`는 가장
  최근 삭제부터 복원하며 저장하거나 설정 창을 닫으면 삭제 취소 기록을 비운다.
- 추가, 편집, 삭제와 순서 변경은 초안만 바꾼다. 저장 전에는 기존 실행 설정과
  단축키 등록을 유지한다.
- 초안에 변경이 있으면 `저장하지 않은 변경 사항`을 표시한다.
- 설정 창을 닫아도 현재 프로세스가 실행 중이면 저장하지 않은 초안은 유지하며, 별도
  확인 창을 표시하지 않는다. 앱이 종료되면 저장하지 않은 초안은 폐기한다.
- 저장 성공 시 삭제 취소 기록을 비우고 모든 카드를 접은 뒤 새 등록 상태를 배지에
  반영한다. Carbon 충돌은 기존 스펙대로 충돌 항목만 비활성화해 저장하고 나머지 후보
  설정은 반영한다.
- 검증 또는 파일 저장이 실패하면 실행 설정을 유지하고 오류가 있는 카드를 펼친다.
  단축키 등록 결과는 기존 스펙의 항목별 처리 규칙을 적용하고 전체 저장 실패로
  취급하지 않는다.
- Command-S는 저장 버튼과 같은 동작을 수행한다.

## 메뉴 바 메뉴

메뉴 바 아이콘을 선택하면 macOS 네이티브 컨텍스트 메뉴를 표시한다. 위에서 아래로
다음 정보를 배치한다.

1. 전체 상태와 활성화되어 등록된 매크로 수
2. 최근 실행 정보
3. `설정…`
4. `Kocro 정보…`
5. `Kocro 종료`

전체 상태의 우선순위와 등록 개수 계산은 기존 스펙을 따른다. 최근 실행 정보는
사용자가 입력한 제목이 있으면 제목을 표시하고, 제목이 비어 있으면
`매크로 A1B2C3D4`처럼 UUID 앞 8자리를 표시한다. 자동 제목의 근거인 입력 문자열은
메뉴 바에 표시하지 않는다. 두 번째 줄에는 단축키, `게시 요청 완료` 또는 구체적인
사전 오류와 상대 시각을 표시한다. 실행 이력이 없으면 최근 실행 영역을 생략한다.

로그인 시 실행 설정은 메뉴 바에 중복해서 두지 않고 `일반` 탭에서만 바꾼다. 권한이
필요한 경우 전체 상태 아래에서 해당 시스템 설정을 여는 동작을 제공할 수 있지만,
정상 상태에서는 설정·About·종료 중심의 짧은 메뉴를 유지한다.

## About

`Kocro 정보…`는 macOS 표준 About 패널을 연다. 앱 아이콘, `Kocro`, 버전과 빌드
번호를 번들 메타데이터에서 표시하고 GitHub 저장소 링크와 저작권 정보를 제공한다.
GitHub 링크는 사용자의 기본 브라우저에서 `https://github.com/caost/kocro`를 연다.

## 접근성

- 카드 헤더의 활성화, 제목, 삭제, 펼치기와 드래그 동작에는 매크로 UUID를 포함한
  고유한 접근성 라벨을 제공한다.
- 상태 배지는 색상만으로 구분하지 않고 텍스트를 함께 표시한다.
- 토큰 편집기는 토큰 전체를 VoiceOver가 순서대로 읽을 수 있게 하고 자동완성 목록의
  현재 선택과 오류를 알린다.
- 키 기록은 마우스 없이 시작·취소할 수 있어야 하며 모든 주요 동작은 키보드로
  접근할 수 있어야 한다.

## 테스트 요구사항

단위 테스트 또는 호스트 뷰 테스트로 다음 동작을 확인한다.

- 사용자 제목, 문자열 기반 자동 제목과 빈 초안 제목의 표시 규칙
- 한 카드만 펼치기, 새 항목 자동 펼치기와 저장 성공 뒤 모두 접기
- 상태별 배지 문구와 최근 실행에서 사용자 제목 또는 UUID를 선택하는 규칙
- 추가·순서 변경·다중 삭제의 역순 취소와 저장 뒤 취소 기록 제거
- 편집 중 실행 설정 유지, 저장 성공 뒤 교체와 저장 실패 시 기존 설정 유지
- 토큰 파싱, 자동완성 후보 제한, 별칭과 순서 정규화, 필드별 키 범위 검증
- 키 기록과 직접 입력이 같은 `ShortcutDefinition` 또는 `TrailingKey`를 생성함
- 오류가 있는 카드를 펼치고 구체적인 오류를 유지하며 해당 입력으로 포커스를 옮김
- 손상된 설정을 연 경우 모든 탭 위에 교체 경고를 표시하고 저장 실패 동안 유지함
- 메뉴 항목 순서, 최근 실행이 없을 때의 생략과 설정·About·종료 동작
- About 메타데이터와 GitHub 링크
- 카드와 토큰 편집기의 접근성 라벨이 항목별로 구분됨

실제 앱에서는 일반·매크로 탭 전환, 카드 드래그, 토큰 자동완성, 키 기록, 삭제 취소,
저장 성공·실패, 메뉴 바 최근 실행과 About 링크를 확인한다. 창 너비를 줄이거나 매크로
수가 늘어나도 카드의 필수 동작과 저장 버튼에 접근할 수 있어야 한다.

## 수용 기준

1. 설정 창이 승인한 상단 탭과 접이식 카드 구조로 표시되고 한 카드만 펼쳐진다.
2. 제목, 상태, 단축키를 접힌 카드에서 확인하고 모든 필드를 펼친 카드에서 편집한다.
3. 직접 입력과 키 기록으로 같은 토큰 값을 만들며 유효한 값은 표준 VIA 형식으로
   정규화되고 잘못된 값은 구체적인 오류와 함께 보존된다.
4. 추가·삭제·삭제 취소·순서 변경이 초안에만 적용되고 저장 성공 전에는 실행 설정을
   바꾸지 않는다.
5. 저장 성공 뒤 카드와 상태 배지가 갱신되며 실패하면 오류가 있는 카드와 기존 실행
   설정을 유지한다.
6. 메뉴 바에서 상태, 등록 개수와 최근 실행을 확인하고 설정, 표준 About과 종료를
   실행할 수 있다.
7. 최근 실행은 사용자 제목이 없을 때 입력 문자열 대신 UUID 앞 8자리를 표시한다.
8. 주요 화면 상태와 키보드·접근성 동작이 자동 테스트와 실제 macOS 앱 확인으로
   검증된다.
